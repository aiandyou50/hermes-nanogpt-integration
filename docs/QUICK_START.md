# AI 에이전트 빠른 시작 프롬프트

## 📋 문서 설명

이 문서는 **Hermes AI 또는 다른 AI 에이전트에 바로 전달 가능한 프롬프트, 설정 정보, 템플릿**을 제공합니다. 복사-붙여넣기로 AI 에이전트가 NanoGPT를 효과적으로 사용할 수 있도록 최적화되었습니다.

**C. 중요 제약사항**
- 토큰 한도

- 응답 시간

- 빠른 응답 모델 목록
- 이미지 모델 목록

- 텍스트 + 이미지 결합

- API 연결 오류
- 응답 타임아웃

#### 6. **성능 최적화 가이드**

#### 7. **추적 및 로깅**

- 사용된 모델

#### 8. **보안 지침**

- API 키 관리
