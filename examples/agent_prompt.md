# AI 에이전트 프롬프트 템플릿

## 📋 문서 설명

이 문서는 **Hermes AI 또는 다른 AI 에이전트에 복사-붙여넣기로 바로 전달 가능한 프롬프트 템플릿 모음**입니다. 각 프롬프트는 NanoGPT의 기능을 효과적으로 활용하도록 최적화되었습니다.

---

## 🎯 작성 지침

다음 내용을 작성해주세요:

### 📌 포함되어야 할 섹션

#### 1. **텍스트 생성 프롬프트**

각 프롬프트마다:
- 프롬프트 제목
- 설명
- 권장 모델
- 프롬프트 내용 (복사 가능)
- 매개변수
- 예상 출력

**포함할 프롬프트:**
- 블로그 글 작성
- 마케팅 카피 작성
- 기술 문서 작성
- 소셜 미디어 포스트
- 이메일 작성
- 코드 생성
- 기타 창의적 글쓰기

#### 2. **이미지 생성 프롬프트**
- 프롬프트 제목
- 스타일 설명
- 권장 모델
- 이미지 생성 프롬프트
- 해상도 설정
- 생성 팁

#### 3. **데이터 처리 프롬프트**
- 데이터 분석
- 데이터 변환
- 데이터 시각화

#### 4. **대화형 프롬프트**
- 채팅 봇
- Q&A
- 상담

#### 5. **배치 처리 프롬프트**
- 여러 작업 한번에 처리
- 효율적인 토큰 사용

#### 6. **조건부 프롬프트**
- if-then 구조
- 상황별 분기

#### 7. **프롬프트 작성 팁**
- 효과적인 프롬프트 구성
- 변수 사용법
- 토큰 절감 방법

---

## 📝 작성 형식

```markdown
# AI 에이전트 프롬프트 템플릿

## 📋 문서 설명

## 텍스트 생성

### 1. 블로그 글 작성

**설명**: SEO 최적화된 블로그 글을 작성합니다.

**권장 모델**: text-generation-large

**복사할 프롬프트**:
\`\`\`
당신은 전문 블로그 작가입니다.

다음 주제로 1,500단어의 블로그 글을 작성해주세요:
주제: [TOPIC]
대상 독자: [AUDIENCE]
톤: [TONE]

 SEO 최적화된 제목과 함께 작성하고,
적어도 3개의 소제목을 포함해주세요.
\`\`\`

**매개변수**:
- [TOPIC]: 글의 주제
- [AUDIENCE]: 대상 독자층
- [TONE]: 글의 톤 (전문적/친근한/학술적 등)

**예상 토큰**: ~2,000 tokens

**예상 출력**:
제목 + 서론 + 본문 (3개 섹션) + 결론

### 2. 마케팅 카피

**설명**: 제품 광고용 마케팅 카피

**권장 모델**: creative-text-model

**복사할 프롬프트**:
\`\`\`
당신은 전문 마케팅 카피라이터입니다.

다음 제품의 광고 카피를 작성해주세요:
제품명: [PRODUCT]
주요 기능: [FEATURES]
대상 시장: [TARGET]
광고 채널: [CHANNEL]

강력한 CTA(행동 유도)를 포함하고,
감정적 호소력을 극대화해주세요.
\`\`\`

## 이미지 생성

### 1. 마케팅 배너

**권장 모델**: image-generation-pro

**복사할 프롬프트**:
\`\`\`
Create a professional marketing banner image:
Style: [STYLE]
Color scheme: [COLORS]
Main message: [MESSAGE]
Resolution: 1920x1080
\`\`\`

### 2. 일러스트

**권장 모델**: illustration-model

**복사할 프롬프트**:
\`\`\`
Create an illustrated image:
Subject: [SUBJECT]
Art style: [STYLE]
Mood: [MOOD]
Colors: [COLORS]
\`\`\`

## 데이터 처리

### 1. 데이터 분석

**권장 모델**: analysis-model

**복사할 프롬프트**:
\`\`\`
다음 데이터를 분석하고 인사이트를 제공해주세요:

데이터:
[DATA]

분석 항목:
1. 주요 패턴
2. 예외 사항
3. 추천 사항
\`\`\`

## 대화형 (Conversational)

### 1. 고객 지원 챗봇

**복사할 프롬프트**:
\`\`\`
당신은 친절한 고객 지원 담당자입니다.

고객 질문: [QUESTION]
회사 정책: [POLICY]
제품 정보: [INFO]

해결책을 제시하거나 적절한 팀으로 안내해주세요.
\`\`\`

## 배치 처리

### 1. 여러 제목 생성

**복사할 프롬프트**:
\`\`\`
다음 주제에 대해 5개의 서로 다른 제목을 생성해주세요.
각 제목은 30자 이내여야 합니다.

주제: [TOPIC]

형식:
1. [제목 1]
2. [제목 2]
...
\`\`\`

## 조건부 프롬프트

### 1. 동적 응답

**복사할 프롬프트**:
\`\`\`
사용자 입력: [USER_INPUT]

다음 조건에 따라 응답해주세요:
- 만약 [조건 1]이면 → [응답 1]
- 만약 [조건 2]이면 → [응답 2]
- 그 외에는 → [기본 응답]
\`\`\`

## 프롬프트 작성 팁

### 효과적인 프롬프트 구성
1. **역할 정의**: "당신은 전문 X입니다."
2. **작업 설명**: "다음을 해주세요..."
3. **맥락 제공**: "배경: ..."
4. **요구사항**: "조건: ..."
5. **출력 형식**: "형식: ..."

### 변수 사용법
\`\`\`
[변수명] 형식으로 표시
사용자가 자신의 값으로 대체
\`\`\`

### 토큰 절감 방법
- 짧고 명확하게
- 불필요한 단어 제거
- 핵심만 강조
- 예시는 필요할 때만
```

## 💡 작성 팁

✅ **복사-붙여넣기 가능**: 그대로 복사해서 바로 사용
✅ **변수 명확**: [변수명]으로 표시하여 사용자가 쉽게 수정
✅ **다양한 종류**: 텍스트, 이미지, 데이터, 대화 등 포함

✅ **토큰 예상**: 각 프롬프트의 토큰 소비량
